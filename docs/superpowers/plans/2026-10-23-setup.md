# Setup de dependências e ferramentas — Implementation Plan

> **Para agentes executores:** este plano é registrado como track via `conductor-new-track` e executado com `conductor-implement`, seguindo `conductor/workflow.md` (um commit por task com resumo de 3–5 linhas no corpo, SHA no `plan.md` da track). Steps usam checkbox (`- [ ]`).

**Goal:** Instalar e configurar todas as bibliotecas e ferramentas do projeto, cada uma funcionando no app (iOS/Android) e no Jest, antes de qualquer tela.

**Architecture:** Uma task por grupo de bibliotecas. Cada task instala, configura (Metro, Babel, Jest, nativo) e prova que a biblioteca carrega no Jest com um smoke test em `src/test/libraries.test.tsx`. A verificação nativa (build iOS e Android) fecha a track.

**Tech Stack:** React Native 0.88 (CLI), TypeScript, Yarn 1.22. Versões alvo: react-native-svg 15.16, react-native-svg-transformer 1.5, lottie-react-native 7.5, react-native-safe-area-context 5.10, @react-navigation/native 7.5 + native-stack 7.21 + bottom-tabs 7.21, react-native-screens 4.30, react-native-asset 2.3, zustand 5.0, @react-native-async-storage/async-storage 3.1, @testing-library/react-native 14.1 + test-renderer 1.3, husky 9.1, @commitlint/cli + config-conventional 21.2.

## Contexto

Base atual: RN 0.88 CLI com Restyle, Reanimated 4 + worklets (plugin no Babel) e safe-area-context já instalados, mas nada commitado além do setup do Conductor. Este é o plano inicial: deixa a stack completa e verificada, para que as tracks seguintes só usem as bibliotecas, sem instalar nada.

## Não-objetivos

- Usar as bibliotecas em telas reais (tema, navegação, splash): tracks seguintes.
- Tokens de design no código: tracks seguintes.
- E2E.

## Decisões

| Decisão | Escolha | Motivo |
|---|---|---|
| Entry | `App.tsx` → `src/App.tsx` (named export); remove template (`@react-native/new-app-screen`, `__tests__/`) | Tudo em `src/`, regra de named exports |
| Testes | RNTL 14 (`render`/`fireEvent` assíncronos) + `test-renderer`; remove `react-test-renderer` e `@types/react-test-renderer` | Versão atual para React 19 |
| Jest | `resolver` do Reanimated, `jest.setup.ts` com mocks de todas as libs nativas, `transformIgnorePatterns` próprio, cobertura ≥ 80% | `workflow.md` |
| Smoke tests | `src/test/libraries.test.tsx`, um `describe` por biblioteca; `src/test/**` fora da cobertura | Prova que Jest transforma e mocka cada lib, sem testar a lib em si |
| SVG | `react-native-svg` + `react-native-svg-transformer`; SVGs do design normalizados para `fill="currentColor"` | Ícones tingidos via prop `color` (aba ativa/inativa, tema) |
| Fontes | `react-native-asset` com `react-native.config.js` apontando `./src/assets/fonts`; Montserrat Regular/Medium/SemiBold/Bold | Linka iOS (`UIAppFonts`) e Android (`assets/fonts`) sem passos manuais |
| Navegação | native-stack + bottom-tabs + screens; Android `MainActivity.onCreate(null)` | Exigência do `react-native-screens` (evita crash ao restaurar a activity) |
| Hooks git | `commit-msg`: commitlint; `pre-commit`: lint + typecheck; `pre-push`: testes | Commit rápido, push seguro |
| commitlint | `config-conventional` + tipo `conductor` | Commits do Conductor (`conductor(plan): ...`) |

## Critérios de aceite

1. Todas as bibliotecas listadas no Tech Stack estão em `package.json` nas versões alvo.
2. `src/test/libraries.test.tsx` passa: SVG importado como componente, Lottie, navegação (stack e tabs), Zustand persistido em AsyncStorage, safe area.
3. Commit fora do padrão é rejeitado; `conductor(plan): ...` é aceito; pre-commit roda lint + typecheck.
4. `yarn ios` e `yarn android` compilam e abrem o app; Montserrat registrada nos dois.
5. `yarn lint`, `yarn typecheck` e `CI=true yarn test --coverage` passam.
6. README lista a stack e os comandos.

## Global Constraints

- Gerenciador: **yarn** (nunca npm). Após dependência nativa: `cd ios && bundle exec pod install`.
- Named exports em `src/` (exceção: configs `*.config.js`, `babel`, `metro`, mocks).
- RNTL 14: `render`, `fireEvent`, `act`, `renderHook` são **async** — sempre `await`.
- Commits: Conventional Commits, subject em minúsculas, corpo com resumo de 3–5 linhas.
- Verificação: `yarn lint`, `yarn typecheck`, `CI=true yarn test`.

## Review Focus

1. **Lib ESM não transformada pelo Jest** (`SyntaxError: Cannot use import statement`) — cada smoke test pega isso; se aparecer, incluir o pacote em `transformIgnorePatterns`.
2. **SVG com cor fixa** — ícone ignora a prop `color`. Teste na Task 4 (`fill` = `currentColor` em todos os arquivos).
3. **Fonte não registrada no iOS** (nome PostScript ≠ nome do arquivo) — conferir `UIAppFonts` e renderizar texto com `fontFamily: 'Montserrat-SemiBold'` na verificação manual (Task 8).
4. **Crash no Android ao voltar do background** sem `onCreate(null)` — verificação manual na Task 8.
5. **Hook bloqueando commit do próprio Conductor** — Task 2 testa `conductor(plan): ...`.
