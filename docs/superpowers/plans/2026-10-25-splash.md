# Splash animada — Implementation Plan

> **Para agentes executores:** este plano é registrado como track via `conductor-new-track` e executado com `conductor-implement` (num subagente), seguindo `conductor/workflow.md` (um commit por task com resumo de 3–5 linhas no corpo, SHA no `plan.md` da track). Steps usam checkbox (`- [ ]`).

**Goal:** O tema passa a seguir o modo do sistema (ao vivo). Ao abrir o app, o FIAP rosa se desenha traço a traço sobre o fundo do tema e entrega para a tela de destino: no Login a logo viaja até o lugar dela (mudando para turquesa e completando com o selo SCHOOL); em Aulas some com fade.

**Architecture:** O tema ganha o modo `system` (padrão), resolvido com `useColorScheme()`, que reage na hora a trocas manuais ou automáticas do sistema. Splash nativa só com o fundo do modo do sistema (preto/branco, sem logo parada), que casa com o tema do app. Por cima do `RootNavigator`, um `SplashOverlay` em JS desenha a logo vetorial (`FiapStrokeLogo`, `react-native-svg` + Reanimated) enquanto a sessão reidrata; quando a reidratação termina e o desenho acaba, escolhe a saída conforme o destino e se desmonta.

**Tech Stack:** `react-native-svg`, Reanimated 4 (`useAnimatedProps`, `interpolateColor`, `withTiming`/`withDelay`/`withSequence`), Zustand — tudo instalado. Nada novo.

**Spec:** decisões do usuário nesta conversa (2026-10-25) + `conductor/product-guidelines.md` (Animações: splash ≤ 2s, não atrasa o app pronto, reduzir movimento). Logo vetorial: Figma `lS5jNff8UuWaPnOPZWxb8n`, página Capa, node `4001:4` ("Logo FIAP", 798×216, traço de ~15,8 de espessura).

## Decisões

| Decisão | Escolha | Origem |
|---|---|---|
| Efeito | Traços do FIAP se desenhando como caneta, letra a letra F → I → A → P, cada letra começando antes da anterior terminar | Usuário |
| Cor do desenho | Rosa `brand` (`#ED145B`) | Usuário |
| Tema | Modo `system` por padrão (segue o celular, inclusive trocas automáticas por horário, ao vivo); `light`/`dark` manual sobrepõe — botão de tema continua para depois | Usuário |
| Splash nativa | Só o fundo do modo do sistema: escuro `#000000`, claro `#FFFFFF` (= `background` dos temas), iOS e Android | Usuário |
| Status bar | Ícones claros no tema escuro e escuros no claro (`StatusBar barStyle` conforme o tema) | Minha escolha |
| Saída → Login (sem sessão) | Logo sobe e encolhe até o retângulo da logo do Login, cor rosa → `accentText` turquesa durante a viagem; no fim, cross-fade para o PNG real do Login (que traz o selo SCHOOL) e o overlay some | Usuário ("vamos tentar a 2… a transição") |
| Saída → Aulas (com sessão) | Fade simples do overlay | Usuário |
| Plano B | Se a viagem ficar ruim no aparelho, saída por fade simples também no Login | Usuário ("se não der certo, fazemos a 1") |
| Reduzir movimento | Logo aparece com fade (sem desenho nem viagem) e o overlay some com fade | Guidelines |
| Duração | Duração alvo de até 2,7 s, validada visualmente em dispositivo (decisão de UX: desenho mais lento ficou melhor no aparelho) | Guidelines |
| Traços | Redesenhar cada letra como **linha central** (`stroke`, `strokeLinecap="butt"`, largura igual à espessura do Figma) para o efeito de caneta; visual final idêntico à logo | Minha escolha, aprovada |

## Tempos (constantes no `motion` do tema)

`motion.splash = { letterDuration: 700, letterStagger: 250, hold: 150, travel: 600, handoff: 150, fadeOut: 250 }` → desenho ≈ 1450 ms; Login ≈ 2600 ms; Aulas ≈ 1850 ms (desenho + hold + fadeOut). Ajustáveis no checkpoint.

## Global Constraints

- Named exports; `type Props`; um componente por arquivo; testes ao lado do código; **sem comentários no código** (o porquê vai no corpo do commit).
- Identificadores em inglês; textos visíveis em português.
- Só tokens do tema/`motion`; medidas do Figma sem token como constantes nomeadas; `StyleSheet` no fim do arquivo.
- Reanimated, nunca `Animated` do core; animar só `transform`, `opacity`, `strokeDashoffset` e cor.
- Nunca bloquear: a splash não atrasa a reidratação nem a navegação; a tela de destino já está montada por baixo.
- Commits Conventional Commits, subject minúsculo, corpo 3–5 linhas, **sem `Co-Authored-By` ou atribuição**. Nunca adicionar `docs/superpowers/plans/` aos commits nem as mudanças locais de assinatura em `ios/FiapTeste.xcodeproj/project.pbxproj` (Team/Bundle ID do usuário) — se o arquivo precisar mudar, commitar só o necessário com `git add -p`.

## Review Focus

0. **Modo do sistema muda com o app aberto** (ex.: iOS automático no fim da tarde) → tema troca na hora, sem reiniciar. Teste na Task 0.
1. **Reidratação mais lenta que o desenho** → overlay espera a reidratação antes de escolher a saída; nunca mostra Login para quem tem sessão. Teste na Task 3.
2. **Reidratação mais rápida que o desenho** → o desenho termina antes de sair (a splash não é cortada no meio). Teste na Task 3.
3. **Reduzir movimento ligado** → sem desenho nem viagem, só fades. Teste na Task 3.
4. **Toque durante a splash** → overlay bloqueia toques até desmontar (o destino já montado não recebe toque fantasma). Teste na Task 3.
5. **Posição final ≠ logo do Login** (safe area, tela pequena) → o retângulo de destino vem das mesmas constantes do Login (`LOGO_TOP`, `LOGO_SIZE`), exportadas de um único lugar. Verificação manual no checkpoint.

## Fase 2: Splash animada

**Interfaces:**
- Produces: `FiapStrokeLogo({ progress, color, width }: { progress: SharedValue<number>; color: SharedValue<string> | string; width: number })` — `Svg` com `viewBox="0 0 798 216"`, um `AnimatedPath` por traço; cada traço revela via `strokeDasharray = length` e `strokeDashoffset` animado a partir de `progress` (0 → 1), com a janela de cada letra calculada por `letterDuration`/`letterStagger`. ### Task 3: Overlay da splash e saídas

**Files:**
- Create: `src/components/SplashOverlay/SplashOverlay.tsx`, `SplashOverlay.test.tsx`
- Modify: `src/App.tsx` (renderiza `SplashOverlay` acima do `RootNavigator` até `onFinish`), `src/screens/Login/Login.tsx` (exportar `LOGO_TOP`/`LOGO_SIZE` de um módulo compartilhado, ex.: `src/screens/Login/loginLayout.ts`, usado pelo Login e pelo overlay)

**Interfaces:**
- Consumes: `FiapStrokeLogo`, `useSessionHydrated()`, `useSessionStore(s => s.guardianId !== null)`, `useReducedMotion()`, `motion.splash`, `loginLayout`, PNG `logo.png`.
- Produces: `SplashOverlay({ onFinish }: { onFinish: () => void })` — `View` absoluto em tela cheia, fundo `background` do tema resolvido, `pointerEvents="auto"` (bloqueia toques). Sequência:
  1. Desenho (`progress` 0 → 1). Logo centralizada, largura ≈ 306 (mesma do Login) para a viagem ser só translação + pequena escala.
  2. Quando **desenho terminou E sessão reidratou**:
     - sem sessão: `hold` → `travel` (translateY até `LOGO_TOP`, escala para casar com a parte FIAP do PNG; `color` rosa → `accentText` com `interpolateColor`) → `handoff` (PNG do Login aparece no mesmo retângulo por cima, SVG some) → fundo do overlay some (`fadeOut`) revelando o Login já montado → `onFinish`;
     - com sessão: `hold` → overlay inteiro some (`fadeOut`) → `onFinish`.
  3. Reduzir movimento: logo com `progress` já em 1 aparece com fade; ao reidratar, overlay some com fade → `onFinish`.
  O retângulo da parte FIAP dentro do PNG (250×40, FIAP à esquerda, selo SCHOOL à direita) é medido uma vez e guardado como constante proporcional (`FIAP_IN_PNG = { x, width }` em fração da largura).

- [ ] **Step 1: Testes que falham** (fake timers; mock de `useReducedMotion` e da reidratação)
  ```ts
  it('waits for hydration before leaving', ...);          // desenho acabou, não reidratou → onFinish não chamado
  it('finishes the drawing before leaving', ...);         // reidratou cedo → onFinish só após o desenho + saída
  it('goes to Login with the logo handoff', ...);         // sem sessão → PNG "FIAP School" visível no fim, depois onFinish
  it('fades out to the main screen with a session', ...); // com sessão → onFinish sem handoff
  it('only fades when reduce motion is on', ...);         // onFinish em ≤ fadeOut*2 após reidratar
  it('blocks touches while visible', ...);                // pointerEvents 'auto'
  ```
- [ ] **Step 2:** Rodar → FAIL.
- [ ] **Step 3:** Implementar; `App` guarda `splashDone` em `useState` e desmonta o overlay no `onFinish`.
- [ ] **Step 4:** `yarn lint && yarn typecheck && CI=true yarn test` → PASS (o e2e do `RootNavigator` não muda; testes do `App` avançam os timers da splash).
- [ ] **Step 5: Commit** `feat(splash): animate the logo into the first screen`

- [ ] **Task: Phase Verification & Checkpoint** — manual em iOS e Android: desenho fluido; sem sessão a logo chega exatamente sobre a do Login (sem pulo de posição/tamanho/cor) e os campos aparecem; com sessão vai para Aulas com fade; reduzir movimento; tempo total até 2,7 s.
